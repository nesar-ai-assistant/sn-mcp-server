Supernova Cosmology MCP Server (Type Ia SNe: Pantheon+, DES-SN5YR, Union3/UNITY1.5, optional DES-Dovekie). Start with list_sn_datasets / describe_sn_dataset; list_sn_skills for recipes (sn-tour first). Conventions: z = zHD (CMB + peculiar-velocity corrected), mu in mag, D_L = (1+z_hel) D_M(z_HD), H0 in km/s/Mpc; the SN absolute magnitude M and H0 are degenerate, so every fit and chi2 marginalises the additive offset analytically with the FULL stat+sys covariance - absolute mu levels and H0 carry no cosmological information here. Pantheon+ fits default to z > 0.01 (Brout+22); 'calibrators' include/exclude/only selects the 77 Cepheid-host rows. Union3 is a 22-node compressed (binned) Hubble diagram, not per-SN. Typical chain: fetch_sn_sample -> plot_hubble_diagram / bin_hubble_diagram -> fit_sn_cosmology (heavy) -> plot_sn_contours -> compare_sn_samples; compute_distance_modulus gives theory curves and compute_sn_chi2 tests a single model. Tools that write files take an output_dir and return ArtifactResult; pass file paths between tools, never raw arrays. Heavy tools (fit_sn_cosmology, compare_sn_samples mode=contours) can run on ALCF/NERSC via the hep-genesis IRI dispatch engine (set_dispatch / export_dispatch_pack); this server holds no facility credentials.
